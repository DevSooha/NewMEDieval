# MEDieval - 약제사 이야기

재료를 모아 포션을 제조하고, 포션에 따라 달라지는 탄막으로 적과 보스를 상대하는 **2D 탑다운 전투 RPG**입니다.

## 게임 소개

필드에서 얻은 두 재료를 조합해 포션을 만들고 무기 슬롯에 장착합니다. 공격 시 폭탄에서 탄막이 전개되며, 사용한 재료에 따라 탄막의 형태와 발사 방식, 속성과 피격 효과가 달라집니다.

플레이어는 방을 오가며 재료를 수집하고 전투를 진행합니다. 보스전에서는 각 보스의 공격 패턴에 대응하며 포션을 활용합니다.

## 주요 기능

- **재료 수집·제조:** 필드 아이템 획득, 재료 인벤토리, 두 재료를 이용한 포션 제조
- **장착·전투:** 포션 인벤토리와 무기 슬롯, 폭탄·탄막 공격, 피해·상태 효과
- **필드 탐색:** 방 이동과 월드 오브젝트 관리
- **보스전:** 보스별 공격 패턴, VFX·애니메이션 연출
- **저장·로드:** 플레이어와 인벤토리, 장착 및 월드 진행 상태 저장·복원

## 프로젝트 열기

1. 저장소를 클론합니다.
2. Unity Hub에서 저장소 루트를 프로젝트로 추가합니다.
3. [ProjectVersion.txt](ProjectSettings/ProjectVersion.txt)에 명시된 에디터 버전으로 엽니다.

현재 기록된 에디터 버전은 **6000.2.9f1**입니다. 버전 변경 시에는 위 파일을 기준으로 합니다.
